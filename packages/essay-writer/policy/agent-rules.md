## 阶段与协作

### C01

适用：素材与早期草稿。强制执行。

- **C01.01** 早期草稿先帮助补齐关键细节、困难和转折，先找主线，再定位具体缺口，因果链只是分析视角

### C02

适用：早期草稿的微信反馈。强制执行。

- **C02.01** 早期微信反馈每篇只列两到三个最重要问题

### C03

适用：完整最终修改及clean draft。强制执行。

- **C03.01** 所有文书修改先核实上限和计数单位，整篇最终修改交付使用clean-draft，正文在上限减15至上限之间，较低min不能放宽，内部短稿不能作为完整交付，素材不足先补证且禁止凑字，文件只含完整题目和正文

### C04

适用：全部交付文字；仍按条款内的语言、体裁及条件限定。强制执行。

- **C04.01** 当前任务与适用范围优先，单次反馈保持候选，确认后才长期复用，原文与私密反馈不进 Git

## 交付判定

所有适用子项检查完毕，已有错误修正，明确例外可追溯，失败和未核项清零后，才可报告人工规则复核完成。机器未覆盖的项目不得冒充自动通过；作者/顾问最终核对、质量评分及正式提交仍独立判断。

交付正文只含本题要求的题目与正文。内部回执另存，正常回复简述修正及未解项。不得以检测标签、完成记录或该文件本身证明真实作者、事实准确或录取结果。
