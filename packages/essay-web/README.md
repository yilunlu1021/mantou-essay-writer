# 满托文书工作台

面向员工的独立网站。登录后上传普通正文DOCX或粘贴文字，提供实际题目及本次修改要求，后台使用GLM或DeepSeek完成版本化修改与复核。全部结果是待审材料，原稿、检查说明和正文分开。

开发：先构建两个共享包，再运行本包的pnpm check。部署产物在build/，需要Node22或24；pnpm start启动。运行环境仅填写变量名：ESSAY_DATA_DIR、PUBLIC_ORIGIN、PORT、HOST、BOOTSTRAP_PASSWORD（首次可选）、ESSAY_JOB_BUDGET_CNY（每模型每任务默认10元，允许降低）。数据目录不进入Git，首次管理员信息只写私密文件。后台配置标准API Key，浏览器不保存或读取密钥。

费用按返回usage与官方标准价在服务器内部估算，DeepSeek使用高峰价上限，未知用量单列。每模型每任务上限10元、全站每日50元和每任务48次调用仍在后台限制。所有网页（包括管理设置）、浏览器接口和可下载复核记录均不提供程序费用金额、预算或价格字段；正文及原稿中的真实金额不改写。不要把650词篇幅直接当成完整工作流用量；思考、复核和返修也会计费。真实模型对照与人工采用结果需要另行验证。

常规创建及修改密码仍要求至少12位。业务负责人明确指定的短初始密码仅作一次性受保护运维配置，不放宽日常接口，不公开账号清单或凭据，不覆盖已存在账号。新增员工为普通用户，不能访问管理设置或其他人的任务。
