# 满托文书工作台

面向员工的独立网站。登录后上传普通正文DOCX或粘贴文字，提供实际题目及本次修改要求，后台使用GLM或DeepSeek完成版本化修改与复核。全部结果是待审材料，原稿、检查说明和正文分开。

开发：先构建两个共享包，再运行本包的pnpm check。部署产物在build/，需要Node22或24；pnpm start启动。运行环境仅填写变量名：ESSAY_DATA_DIR、PUBLIC_ORIGIN、PORT、HOST、BOOTSTRAP_PASSWORD（首次可选）、ESSAY_JOB_BUDGET_CNY（每模型每任务默认10元，允许降低）。数据目录不进入Git，首次管理员信息只写私密文件。后台配置标准API Key，浏览器不保存或读取密钥。

费用按返回usage与官方标准价在服务器内部估算，DeepSeek使用高峰价上限，未知用量单列。每模型每任务上限10元、全站每日50元和每任务48次调用仍在后台限制。所有网页（包括管理设置）、浏览器接口和可下载复核记录均不提供程序费用金额、预算或价格字段；正文及原稿中的真实金额不改写。不要把650词篇幅直接当成完整工作流用量；思考、复核和返修也会计费。真实模型对照与人工采用结果需要另行验证。

常规创建及修改密码仍要求至少12位。业务负责人明确指定的短初始密码仅作一次性受保护运维配置，不放宽日常接口，不公开账号清单或凭据，不覆盖已存在账号。新增员工为普通用户，不能访问管理设置或其他人的任务。

## 学生素材与联网研究预览

默认关闭，正式服务不自动迁移。研究预览要求独立数据目录，禁止指向正式 `/var/lib/essaydm` 或未标记的既有数据库。预览使用 `essay_preview_session`，正式版继续使用 `essay_session`；不要复制正式数据库、账号、学生资料或任务。后台仅复用已授权的供应商连接。

```sh
pnpm --dir packages/essay-web/runtime install --ignore-workspace --ignore-scripts --frozen-lockfile
pnpm --filter @mantou/essay-web build
ESSAY_AGENT_PREVIEW=1 \
ESSAY_DATA_DIR=/absolute/private/essay-research-preview \
ESSAY_DSH_RUNTIME_ROOT="$PWD/packages/essay-web/runtime" \
PUBLIC_ORIGIN=http://127.0.0.1:8790 PORT=8790 HOST=127.0.0.1 \
node packages/essay-web/build/server.mjs
```

先读取该独立目录中的首次管理员文件，在本地预览配置标准API连接。没有配置运行时则只提供学生库，不伪称可以联网。GLM可作为写稿模型或通过 `ESSAY_SEARCH_PROVIDER=glm` 提供独立搜索；当前研究调度及网页抓取均仍需要DeepSeek标准API Key，写稿模型选择不切换研究引擎。不得把密钥写进环境示例、Git或聊天。

顾问可在“学生与素材”添加本人历稿、经历、访谈和反馈，上传普通正文Word、TXT、Markdown或粘贴内容；每次修订追加版本，状态变化记审计。顾问可新建仅归自己的学生；管理员维护共享顾问。同名不自动合并，切学生清空主表单的原稿、附件及关联要求，防止串用。勾选哪些素材，就保存哪些素材的不可变任务快照；全部取消不会暗中读取其他材料。

“学校研究与本人素材选材”只输出研究与选材记录，允许不提供原稿；不执行正文修改或七类文书复核，不提供正文下载。其他写稿模式先研究再把独立来源上下文传入现有流程，七类复核不减少。采用稿不自动成为已确认事实，生成稿入库时默认待核。额外材料不改写原始来源记录，也不自动消除新增事实检查。

研究使用官方DeepSeek Harness CLI和SDK **0.2.1-rc.5**，在单独任务目录运行，仅注册三种受控工具；禁用默认文件、终端及MCP工具。主服务保管真实Key，子进程只拿短期本机网关token，所有模型/搜索/抓取经过同一内部门禁。固定工具schema、明确终止原因、撤权/取消复查和未知调用不重试分别验证。此限制是对固定受信运行时的约束，不声称构成完整操作系统隔离或上游安全审计。

学校查询由学校/项目/年度与受控主题构造，不把私密文书直接当搜索词。搜索和读取分开；URL、抓取时间、内容hash及准确引文分别留存。准确匹配只核对引文与来源文本，不证明语义、官网身份、申请年度或学生事实；失败引文移除并保留待核状态。远程抓取服务控制网页跳转，最终目的地址未由本服务独立证明。任何研究结果都需顾问核对，不能自动正式采用。

内部沿用每模型每任务10元、全站每日50元和每任务48次调用；研究另限6次模型、4次搜索、4个抓取页面及10次工具操作。独立搜索/抓取账单未返回完整可核价信息时保留估计预留，标记用量未知；不得宣称零成本。网页与下载记录均不显示程序金额。部署到公开测试环境前须另行准备独立数据、账号、TLS和资源边界；本地预览不等于已上线员工测试域名。
