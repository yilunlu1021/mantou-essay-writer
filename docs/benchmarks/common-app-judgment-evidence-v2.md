# Common App个人叙事评分系统 v2.1

版本：judgment-evidence-95plus5-2.1。制定日期：2026年10月25日。业务负责人本轮明确要求更新正式评分版本，新增选材与成长依据的完整诊断，替代只在流程文字中提醒的做法。保留v2.0的主体95、整体附加5、83内部通过线及10项核心最低4分。真实跨顾问稳定性继续用实际文章校准。

## 1. 评价对象与结构

评价当前正文使陌生读者认识作者、理解其判断与信服其行动的程度。现阶段用于满托内部改稿和质量放行，不推算录取概率。

主体95分：人物与个人判断25，因果与脉络25，行动与证据25，叙事取舍10，作者声音与语言10。19项分别给0至5整数。附加只保留额外辨识度整体1项，0至5分。20项相加，满分100。没有原始31分，也不再将多条附加路径累加后封顶。

人物问认识了怎样的人。因果问为何这样判断、回应或选择。行动问实际怎样做、本人做了什么及依据。叙事问信息怎样取舍和推进。语言问表达是否准确并贴合叙述者。相同段落可以支持不同问题，扣分须分别说明具体损失，并指定缺陷的主要归属。

普通题材、朴素语气、平静经历和稳定性格都能取得主体95分。人物深度由具体关切、判断和选择的分量判断，不统一要求痛苦、失败、牺牲、成长、罕见经历、领导职位或量化成果。

## 2. 83分内部通过线

83是中等偏高的内部质量通过线。0至69为需重做，70至79为方向可能成立但尚未达到可交付质量，80至82继续内部修改，83至87为质量通过区间，88至92为强稿，93至100为卓越候选。区间是本轮业务解释，需由真实文章锚点校准，不声称已获统计验证。

学生通读稿必须完整评分且总分至少83，并通过核心判断、因果、行动与陌生读者理解检查。不能通过降低个人目标、提高附加、顾问接受实质缺口或选择有利重跑结果来放行。任何项目未评，完整总分留空，不按比例补齐。

核心项目固定为P1.3、P1.5、C2.2、C2.3、C2.4、E3.1、E3.2、E3.3、E3.5、N4.1，每项至少4分。另逐一完成因果链、行动证据与陌生读者首读三项检查，任一关键问题未解决仍不能交学生。高总分可以与核心未通过同时出现，报告同时保留原始总分与未通过原因，不通过硬压总分掩盖诊断。

质量合格、学生通读、顾问采用与正式提交分别记录。学生最终确认不作为首次给学生通读的前提。来源真实性、题目、字数、作者责任和最终确认继续独立检查。检测分数不改变本量表得分。

低于83的正文保留在顾问内部修改区。内部归档不等于交给学生，受众声明也不认证飞书权限。低分正文不能放入已知学生可见目录，未知可见性时保留本地或使用明确的顾问内部目标。学生交付必须绑定当前评分正文、准确目标与受众，旧内部回执不能复用为学生交付成功。

## 3. 首读与证据规则

先固定实际写作题目、完整正文及段号、正文快照、完整规则和例子版本、所需来源、统一输出模板。首轮独立评阅不看历史总分、预设目标分、写稿者身份和其他评阅结论。评阅者如已参与改稿或已见历史评分，明确记录，不能补称盲评。

先用朴素语言写清：作者在意什么，如何作判断，实际做了什么，读完认识了怎样的人。列出首读时仍需顾问补讲的关键问题。对于变化故事，辨明原判断、新情况、本人回应和后续选择。对于稳定性格或关系故事，辨明处境、判断依据、选择和人物认识，保持同一证据要求。

每项先引准确正文，再解释其支持什么、最强的其他读法或缺失条件，最后选充分成立的档。3分可以读懂，但该项仍有需要补足的关键部分。4分表示本项核心任务已清楚、充分、可信。5分须正面说明较4分增加的具体质量，不能只写没有矛盾、没有夸大或没有明显问题。5分单列完成证据、最强反向读法、为何4档不足三个字段。

满分不要求增加事件、复杂句、困难或篇幅。若现有素材充分，依靠取舍与连接即可提高质量。若决定性动机或行动缺资料，应保留未解决状态。经用户授权的第一人称心理、普通交流和轻微衔接重构单列内部记录，不改写为已核验事实。身份、贡献、数据和成果保持真实来源。

细节须承担功能：让读者看清行动对象、实际条件、判断依据或后果。数字、颜色、术语和操作数量不自动加分。核心场景需要足够的因与果，步骤清单本身不能替代可信故事。首读检查只补必要条件，不要求解释所有技术细节。

### 3.1 逐项评分前的选材与成长诊断

新增必填storyDiagnosis，绑定当前正文及完整有序的逻辑自然段。先说明主线对本人有何分量，再逐段记录叙事任务、新增人物认识与保留理由。换动作重复证明同一层耐心、尊重或努力，须标记repeats，不能因每个动作都清楚就认定人物已经充分。

明确采用单段经历还是相互关联的经历。变化故事说明原有判断、受到的实际检验、本人回应与变化范围。稳定性格故事说明持续立场如何在处境中得到支持。跨经历可形成比较、检验或有来源的因果，时间先后不能替代联系。

转折分别声明读者预期偏离、本人预期受检验、普通关系推进或无转折。无读者意外可以充分，单段故事也可以充分。声明none时不能同时以expectation主张预期偏离附加，仍可使用有依据的其他附加路径。友好回应、趣味细节及场景回扣要说明其实际作用，名校、分数、排练次数或多个活动均不自动证明个人成长。

paragraphProgression须逐段完整有序覆盖。development非supported、任一段落repeats或unresolved，以及总体verdict非sufficient，均阻塞质量通过。顶层充分结论不能覆盖局部缺口。记录合同升为judgment-evidence-assessment@3，旧@2及旧评分保留历史，不自动转换。程序核对覆盖、引用、状态与绑定，不能认证自由文本判断正确或学生已经认可反思。

缺口主要归属人物分量与完整认识P1.1/P1.5、现实检验C2.2/C2.4、跨段主线C2.5及篇幅推进N4.1/N4.2。每项分别说明实际损失，不能把同一条「故事薄」复制扣分。附加仍只整体计一次。

## 4. 附加分仅整体计一次

先完成主体，再检查最强的有效处理增加了什么额外认识。可沿非显然洞察、真实预期偏离、有效象征、经比较成立的少见经验、具有额外认识的价值实践取证，只保存整体得分和所用路径，禁止按路径分别累加。

一般的善良、努力、独立、合作与尊重，在主体中评价其是否成立。附加须指出这些判断之外增加的具体认识。文采、名校或昂贵资源、特殊身份、圆满结局及首尾出现同一名词均不能自动得分。

预期偏离须说明事件发生前的完整正文建立了什么预期，纳入紧邻事件的新信息。人物前后不同不自动构成读者意外。象征须说明载体、对应与实际增加的理解，实义动作重复不自动形成象征。稀缺路径须有可比的生活情境或授权案例参照，列明常见路径、真实差异与限制。活动类别清单本身不足以证明具体做法少见。

只要全文和判断已完成，无有效额外认识可记0。若唯一拟用路径缺必需比较依据，附加未评而非凭印象补分。其他有充分依据的路径可单独支持整体判断，不让缺少稀缺案例库阻塞所有普通题材。各路径只记录候选与取舍，最终整体得分不得累加。

## 5. 档位与校准

以下逐项表与上述规则共同使用。19项全部4分为76，即使附加5也只有81。83附近需要部分项目有充分最高档依据，不能为跨线倒推分项。分数区间不能充当正文证据。

本轮业务负责人对具体旧稿给出的78至80判断与因果、行动缺口，作为私密真实校准案例保留。它用于检查量表与评阅是否对具体缺陷敏感，不能把任何新稿固定打到该区间，也不把单个案例当成全题材已验证金标。

同项相差2档、0与未评争议、额外路径成立与否争议、或总分差异跨过83时，复核双方引文、档位与完整输入，不取平均数。保留各轮原分与裁定理由。校准通过后只声明已覆盖的案例，继续补充不同题材、语气、分数段和作者的真实样例。

## 6. 边界练习

以下为构造练习，只解释取证，不作为已验证真实文章锚点。

甲：作者说家人曾被更强同伴难住，随后选择不同课程。若只写因此学会做自己，缺少新情况怎样影响课程判断及本人如何比较，C2.2与C2.3仍不能过核心线。改进须写出有来源的认识、需求与比较过程，转场词无法补足它。

乙：作者说组织了多处摊位并调整布局。若关键现场只用我安排好了带过，E3.1不足。若能看清参与者卡在哪里、本人怎样回应、变化如何影响活动，具体且足够的片段可过线。无需追加夸张人数、失败或捐款金额。

丙：此前一直隐瞒困难，紧邻求助前已说明情况持续恶化。求助可能是此时读者的合理预期。该行为仍可支持人物与因果，附加预期偏离须另行论证。结尾重要不等于结尾意外。

丁：整理共享冰箱的平静故事，只要本人在意、对家人需要的判断与调整充分具体，可以取得高主体分。故事没有失败、名校、稀缺资源或隐喻时，不据此扣主体。额外对应只有在增加具体理解时才计入整体附加。

4：具体处境、感受或关系解释了关键投入。
