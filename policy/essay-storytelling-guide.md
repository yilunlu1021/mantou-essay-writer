# 文书故事层修改手册

版本1.3.0，2026-10-28确认。内容硬规则只在[语言规范](language-standards.md#故事层修改规范)维护，本手册保留构思方法与记录方式，沿用前轮精简，增加中间经历、阅读焦点及强执行合同。文书修改先读两者，按题型和当前edit/revision范围执行；专业动机、未来计划和学术题不强套个人故事。

## 先认识人和题目

主文书应让读者记住成绩与活动列表之外的作者：在意的事情、作选择的依据、面对摩擦的反应及与人相处的样子。朴素动机、幽默、尴尬、好奇或较真均可有分量，项目级别和奖项不能代替人物。具体故事承担证据，主题由经历支持。全部适用要求和子项按语言规范强制执行，未核或失败不能称合规完成。

先读学生原话和本题，区分学生在意的内容与顾问解释，记录反复出现的偏好、关系、判断及未解问题。用朴素语言提出人物假设，再回来源检验。隐去活动名、学校和奖项后，若仍能认出作者的选择与性格，素材就有个人价值。技术介绍只保留读懂选择所需的部分，本人与工具、老师和团队贡献分别说明。

## 从已有细节发展故事

1. **找锚点。** 在原稿或口述中标出具体动作、对象、交流和限制，选择能解释动机或后续选择的细节。资料存在不等于必须写，天气、气味和精确数字须有作用。
2. **展开过程。** 用已有材料说明动作如何发生、为何此刻必要、遇到什么反馈及后果；不是用同义句拉长篇幅。只有“参加、完成、获奖”时，先定位缺失的本人经历。
3. **标明来源层级。** 内部逐项区分原稿事实、基于来源的展开、普通对白重构、轻微叙事增强和待核对关键假设。重构与增强不回写为档案事实，采用时由本人或顾问通读。
4. **核对例外分量。** 新增轻微细节只按[有限例外](language-standards.md#故事层修改规范)处理，可增强已有摩擦和戏剧色彩；先问删去它是否仍为同一个故事，读者是否会改变对责任、关系或贡献的判断。眼泪、嘲笑、甩门等虽短，仍可能新增冲突，不能自动当作气氛。逐项及合并核对，不能覆盖本人否认的经历。
5. **对白重构。** 已知关系和交流内容可支持普通措辞与口气的重构，无须逐字核验；无来源的关键质疑、决定性动机与重大关系变化不能借对白进入正文。

## 让对象能够辨认

按[具体所指规则](language-standards.md#具体压倒抽象)检查人、学校、时段和动作对象。普通正文some系列为零，不以occasionally/certain/another等同义泛称绕过。a/an + 泛化名词默认重写，极少数必要保留项逐处解释首次引入、分类或计量作用，并说明读者如何定位对象，或该分类/计量功能为何必要。

修改方向是补回来源已给的身份、关系、事件或范围，不是机械a→the，也不必公开无关姓名。首次出现的具体物件可以需要a/an，已知角色可以用my/the定位；不能为冠词合规编学校、日期、频率和数量。缺信息时删去无用泛称或记准确缺口，提问贴原文，避免让学生重新讲整段经历。

## 用本人的应对推进

按真实材料寻找“当时所求 → 新条件或摩擦 → 本人取舍与行动 → 后果或未解问题”。这是阅读路径，不是固定段落模板。取舍、比较与有依据的分析可以支撑行动，操作步骤清楚仍不等于人物充分。

冲突不必是争吵：目标与限制、评价尺度、个人偏好与他人需要之间的真实差异，都能使作者有理由应对。保留对方的合理性，作者可以调整、坚持部分判断或承认暂时无解。其他人的话只提供输入；遮住成长声明后，前面的本人应对仍应支持该认识。行动与主观感受互相支持，不要求每次心情都接后续改进行动。资料缺少行动，不补造结果或顿悟。

平静的发现、持续好奇与顺利尝试也能推进。稳定性格无需强行变化，每段仍须增加处境、检验、选择依据、后果或有依据的主观变化；同层感受换词复述不算推进。不能为追求drama制造失败，也不强迫非叙事题设置冲突。

## 补出被摘要省掉的经历

重要转向先检查来源里已发生、却在稿中被压成“讨论指向某处”的步骤：本人当时的问题、求助、理解建议、选择、尝试或反馈。只展开使读者理解处境和转向所需的部分，不逐次套同一条链。主动求助须有本人发起依据，不把别人安排改成主动争取。

原稿已有期待落差、朴素夸张及兴奋停顿时，保留其用意并按现行句法重组。高潮的阅读空间优先给对本人目标/感受有分量的变化，技术机制按必要性取舍；技术本身是问题关键时保留，不为顺畅而制造高潮。行动已充分传达目的时，删除“我有充分理由”等重复辩解，必要动机、限制及对方理由仍须清楚。

迁移编辑操作，不移植参考稿的事件、情绪、数据或语法错误。一个事件的打开/关闭等状态不同须查真实来源，不当作轻微场景润色；单例Human/Mixed分类不证明句式或改法的检测贡献。

## 进入当时的“我”

按[情境立场规则](language-standards.md#第一人称的情境立场与情感)，在重要动作或转向处辨认：当时所求、选择余地、情愿程度、情绪，以及预期和实际的差别。只选影响理解的部分表达，不每句贴情绪标签。单写I did及流程因果，仍可能缺乏身处其中的感受。

原稿明确感受保留，明确上下文支持的克制推断内部注明；相同动作可能有多种动机时不擅断被迫或兴奋。用准确态度动词、情态、有效形容词或副词和真实对照表达，朴素即可，不靠身体反应或别人评价替代作者自述。保留态度强度与当时视角，后来理解不冒充当时想法。

but/however的对照、actually的认知或预期修正、luckily/unfortunately的利弊评价分别核对，不视为同一种情绪词或自动人味标记。情感SVO有用可保留，但独立核既有配额和禁令；加副词、外挂解释或换句首不取得结构豁免，不能为语法合规删光感受。

## 安排开头与段落

开头尽早聚焦作者正在处理的具体对象与关系，使读者理解眼前处境并愿意跟进。背景随必要性补入，不堆履历、定义和观点，不以隐瞒基本信息制造悬念。

每段内部只记一行：**进入处境与态度 → 本人应对/新增依据 → 情节或期待/情绪的变化 → 下段接手的内容**。另说明独立分段的实际作用，不用“体现成长”代替。相邻段复核三个问题：

- 新段新增什么处境、判断依据、应对、后果或有来路的态度/期待变化？同一情况和意思的重述删并。
- 下一步为何接在这里？显式提示或对象、未解问题、行动后果的隐式承接均可，单加Later/Therefore不能修复缺条件。
- 跨经历是否承接共同未解问题或持续选择？比较也须推进这一问题或取舍，不能作为并排独立故事的豁免，时间相邻不能写成因果。

段落可补此刻必要的背景，前提是它确实使后续选择可理解。分段不按长度配额，不要求每段都冲突升级或立意升高。回忆、比较、时间和因果分别说明，必要时比较完整替代顺序。

## 结尾收住前文

先用作者视角回答：前面这些选择与后果，对这个阶段的我究竟有什么实际分量？高中生不承担顾问代加的成熟道理。无题目或当前用户明确例外时以1-2句完成，停在最后动作、结果或有前文依据的判断均可，开放式与简短归纳式按实际效果选择；不强制回扣或未来计划。

逐句提取最后两段的命题，同义总结只留最充分的一句。比较“事件结果处停住”与“再加一句收束”的版本，删去没有新增作用的句子。两三行仅作排版参考，不用长句塞入盘点，不另起升华、扩大影响或解释回扣。

## 按任务交付

| 任务 | 最小记录与产出 |
| --- | --- |
| 只润色edit | 原稿表达锚点、局部问题及必要修补；不擅改主线，不强增素材。 |
| 构思或revision | 先比较2-3条真正不同的路线，再推荐；路线卡写已有来源、个人动机、摩擦/新条件、本人应对及后果、读者认识、开头、逐段承接、结尾和关键缺口。可以120-200字中文概述，不只换开头画面。 |
| 素材追问 | 只问会改变选题、因果或人物判断的缺口，锚定已有事件并说明答案影响的决定。 |
| 成稿复核 | 先看读者能否跟随并记住人物，再核对事实、声音、逐段增量和收束；执行当前prepare及五类review，不把故事记录当作事实认证、评分或提交批准。 |

路线比较以个人补充、本人投入、阅读兴趣、应对证据和来源状况为据，并检查与其他申请材料的分工。普通经历可以充分；不同证据各有新作用时保留，同一层变化反复证明时压缩。顾问反馈不复制内部流程，私密来源和案例不进入本手册或Git。
